## Tools

Python, pandas, NumPy, scikit-learn, Matplotlib, Jupyter Notebook, and Google Colab. Dependencies are listed in [requirements.txt](requirements.txt).

## Getting Started

Clone or download this repository. Use a Python virtual environment and install the listed dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Open the notebooks in Jupyter or Google Colab. Check each assignment for its dataset paths and setup instructions, then run its cells in order.
